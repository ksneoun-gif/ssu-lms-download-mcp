# 학습 마감 브리핑
MCP 인증 실패 시 같은 플러그인의 `auth-recovery/SKILL.md`를 따른다. 복구된 로컬 MCP 인증과 현재 브라우저의 로그인은 별개이므로, 읽을 브라우저 화면도 실제 접근을 확인한다.
로그인된 LMS의 마이페이지에서 학습활동 목록과 과목별 강의콘텐츠를 읽는다. 과목, 주차, 제목, 마감 시각, 완료 여부를 표로 정리하고 가장 가까운 마감부터 보여준다. Asia/Seoul 기준이다. 동영상·과제·퀴즈를 구분하고 영상 길이가 표시되면 필요한 시청시간을 합산한다. 마감이 같아도 항목별 완료 상태를 확인한다. 목록에 없는 과제나 완료 상태를 추측하지 않는다. 활동을 재생하거나 출석을 자동 처리하지 않는다. 요청이 없으면 새 알림/자동화를 만들지 않는다.
